# ErgouCompress 桌面 UI / UX 原型

直接双击 `index.html`，无需安装依赖或启动服务。原型使用本地 HTML、CSS、JavaScript 和内嵌 SVG；全部业务状态为模拟，不接入生产数据库，不执行编码、清理或迁移。文件选择只展示名称和大小，不读取内容或上传。

本设计从用户流程重新组织，未读取或复用现有 Compose UI。生产界面继续暂缓，先在此原型讨论流程、信息层级和组件状态。

## 信息架构与建议走查

| 页面 | 操作与设计重点 |
| --- | --- |
| 新建任务 | 导入与选择 → 参数与预检 → 冻结确认；主区域展示清单，右侧提供质量、编码器、容器和估算依据 |
| 逐轨抽屉 | Copy / Encode / Drop 按轨明确选择；AAC 参数、默认音轨和容器冲突在创建前解决 |
| 任务队列 | 编码、完整验证、发布核对分阶段；完成当前后暂停、立即停止、从头重跑和取消分别说明 |
| 处理历史 | 结果、事件和档案三个详情视图；隐藏记录与删除媒体分离；备份释放后禁用恢复 |
| 存储与档案 | 按卷展示容量；媒体缩小、备份占用、逻辑删除量与实际磁盘回收分别说明 |
| 工具与设置 | 工具真实自检的状态设计、保留策略、深浅主题和快捷键说明；设置只影响新任务 |

建议先把容器切换为 MP4，查看 ASS 字幕/字体冲突；打开“旅行_精选”的逐轨策略，明确 Drop 后再创建任务。选择原地模式时需要确认备份与替换。队列可运行进度演示、停止后继续，体验“当前文件从头重跑”。存储页勾选版本备份后预览清理，必须额外确认失去恢复能力；存在未完成任务时阻止迁移，取消后可演示四步迁移流程。

## 视觉与交互约定

- 浅灰绿画布、白色内容卡、深绿色主要操作；警告使用琥珀色，破坏性操作使用红色，并提供文字解释。
- `styles.css` 顶部统一管理颜色、圆角和阴影令牌。正文使用 Segoe UI / 微软雅黑，保留密集表格与舒适设置卡两种信息密度。
- 左侧稳定导航，主工作流三步推进；原位预检解释问题，抽屉展示逐项细节，对话框承载最终确认。
- 窄窗口改为单列，表格横向滚动，避免把媒体规格压成不可读碎片。正式桌面表格另需虚拟化，原型不宣称支持万条清单性能。
- 原生 button / input / select / dialog，明确名称、焦点轮廓、进度语义和状态播报。支持 Ctrl O、Ctrl F、Alt 1–5、Esc；减少动态效果遵循 `prefers-reduced-motion`。
- 正式界面应从 `ParameterHelp` 获取完整参数说明，展示 UNKNOWN 估算、离线卷、NeedsAttention、低空间暂停、已消费/过期清理预览等后端状态，不将示例数值写入产品。

## 后续 Compose 对接边界

| 原型动作 | 正式后端契约 |
| --- | --- |
| 创建任务 | `AppWiring.prepareRequest` / `queue.submit`，冻结计划后不读可变设置 |
| 执行与控制 | `queue.recover/run/pause/cancel/retry` 和 `AttemptEvent` |
| 历史恢复 | `commitHistory/restoreCommit`；不可绕开提交日志和原始备份校验 |
| 容量与保留设置 | `storageReport/loadRetention/saveRetention` |
| 清理预览与确认 | `cleanupPreview/cleanupExecute`；传保存的 ID、令牌与备份损失确认，不从界面重新拼删除路径 |
| 诊断与迁移 | `exportSupport/migrateDataRoot`；迁移成功后重启会话 |

未来按页面建立独立 UI 状态与事件处理，平台选择器和窗口能力留在桌面层；通用规则继续留在 sharedLogic。HTML 中的状态机只用于设计评审，不能作为媒体处理实现直接移植。

## 验证

`verification/verify-backend.ps1 -Prototype` 会临时安装 jsdom 26.1.0，执行 `tests/prototype.test.cjs` 的 6 项交互测试，并清理依赖与缓存。测试源码长期保留，生成脚本和数据不保留。

已验证页面切换、搜索焦点、主题、容器冲突、逐轨 Drop、原地确认、停止重跑、暂停、清理确认、恢复禁用、迁移阻止与取消后迁移、历史恢复和设置校验。

浏览器安全策略拒绝本次自动打开本地 `file://` 原型，因此使用不启动浏览器的 DOM 检查。尚未完成实际浏览器的视觉布局、原生 dialog 焦点循环、拖放/文件夹选择、DPI、缩放与读屏验收；DOM 测试不证明这些体验达标。
